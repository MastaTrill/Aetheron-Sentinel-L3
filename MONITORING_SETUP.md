# Sentinel Monitoring & Alerting Setup

## 1. Chainlink Keeper Configuration

Ensure the `SentinelChainlinkKeeper.sol` is registered on the Chainlink Automation App.

- **Gas Limit:** 2,000,000
- **Check Interval:** Every block

### Forwarder Management (Mainnet Post-Deploy)

1. Register the `SentinelChainlinkKeeper` at automation.chain.link.
2. Once the "Forwarder" address is generated by the registry, call `setForwarder(forwarder_address)` on the Keeper contract using the deployer wallet.
3. Verify the `ForwarderUpdated` event is emitted to ensure the Keeper will accept automation calls.

## 2. Alerting Hooks

We use a combination of GitHub Actions and Discord Webhooks for real-time alerting.

### Critical Alerts (Severity 10)

- **Trigger:** `CircuitBreaker.EmergencyHalt` event.
- **Action:** PagerDuty notification + Discord #security-alerts.

### Operational Alerts (Severity 1-5)

- **Trigger:** `SentinelCoreLoop.QuantumCoherenceFailure`.
- **Action:** Log to Grafana + Discord #ops-monitoring.

## 3. Health Checks

Run the following regularly to verify infrastructure health:

```bash
npm run verify:ownership
node scripts/verify-bridge-relayers.cjs
```
