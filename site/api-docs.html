Developer API & SDK Documentation

REST & WebSocket reference for integrating Sentinel L3 security alerts into your dApp.

GET /health

Check Sentinel L3 monitoring gateway status and RPC connection health.

curl -X GET "https://api.aetrs.com/health" -H "Accept: application/json"

POST /api/alerts/trigger

Dispatch real-time emergency threat alert payload to registered webhooks.

curl -X POST "https://api.aetrs.com/api/alerts/trigger" \
  -H "Content-Type: application/json" \
  -d '{"contract":"0x8c1eb...", "severity":"CRITICAL", "type":"FLASH_LOAN"}'

GET /metrics

Prometheus telemetry metrics exporter endpoint.

# HELP sentinel_intercepts_total Total intercepted attack vectors
# TYPE sentinel_intercepts_total counter
sentinel_intercepts_total{chain="base"} 142
