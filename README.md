# Aetheron-Sentinel-L3

Aetheron Sentinel L3 is a reference implementation of an autonomous bridge-defense interceptor.

## What was added now
Aetheron Sentinel L3 is purpose-built for large-scale Ethereum staking operations. It acts as a real-time zero-trust gatekeeper in front of validator RPC endpoints, blocking malicious traffic and slashing attempts before they reach the node. By validating every RPC call and isolating risky behavior, Sentinel protects staked assets and keeps validator uptime high, directly safeguarding annual staking revenue like the $212 million currently generated by BMNR’s 3.33 million staked ETH.

1. **Live JSON-RPC chain wiring with block-height finality & compensating rollback**
   - `JsonRpcOnChainAdapter` supports live endpoint probing (`eth_chainId`, `eth_blockNumber`), receipt confirmation calculation from either `confirmations` or `blockNumber`, and automatic compensating rollback (`rollback_on_unverified=True`) validated over HTTP JSON-RPC (`LocalTestnetRpcServer`).
2. **Real Post-Quantum Dilithium2 backend (`dilithium_py`) & dual-sign staging drills**
   - `RealDilithiumBackend` is wired to `dilithium_py` (`Dilithium2`) for `pq-ext` dual-signed policy packs (`hmac-sha256` + `pq-ext`) with automated rollback on critical governance drift.
3. **Chaos & abuse resilience**
   - Verified against multi-threaded idempotency replay floods, Redis transient/sustained partition recovery, and single-pass adversarial tournament KPIs (`TPR=1.0`, `FPR=0.0`).
4. **Operational controls & two clean staging windows**
   - Added runtime kill-switch (`engage_kill_switch` / `release_kill_switch`), `ExecutionFailureAlarm` alerting, `docs/KILL_SWITCH_RUNBOOK.md`, and `scripts/run_staging_windows.py`.

## Capability stack

- `interceptor.py`: risk engine with actor/bridge/global breakers, kill-switch control, policy-pack overrides, governance auto-rollback, crypto-agility compliance checks, and audit hooks.
- `execution.py`: on-chain adapter abstraction + verified rollback-safe executor with failure budgets, `rollback_on_unverified`, and operation receipts.
- `rpc_adapter.py`: JSON-RPC integration adapter with live endpoint probing, polling, finality checks, and `LocalTestnetRpcServer`.
- `policy_pack.py`: signed/versioned policy packs with staged rollout, dual-sign support, external PQ hooks, and rollback.
- `pq_backend.py`: PQ backend protocol, `MockDilithiumBackend`, and `RealDilithiumBackend` (`dilithium_py`).
- `state.py`: in-memory and Redis state backends for distributed counters/idempotency.
- `governance.py`: calibration record tracking, configurable warning/critical drift alarms, execution failure alarms, and crypto-agility rules.
- `simulation.py`: single-pass adversarial simulation + tournament KPI reporting.
- `staging.py`: automated staging validation runner executing full readiness windows.
- `telemetry.py`: audit event sink interface.

## Quick start

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
python scripts/run_staging_windows.py
```

## Post-quantum dependency

- `MockDilithiumBackend` is deterministic and does **not** require external PQ libraries.
- `RealDilithiumBackend` uses the installed `dilithium_py` (`Dilithium2`) provider at runtime and supports optional 48-byte DRBG seeds for deterministic staging drills.
